# Farmacia-Bom-Saber — API (server)

Projeto inicializado com NestJS, Prisma (SQLite), Zod e Vitest.

Comandos básicos:

1. Instalar dependências:

```bash
npm install
```

2. Gerar Prisma Client:

```bash
npx prisma generate
```

3. Rodar migração inicial (desenvolvimento):

```bash
npx prisma migrate dev --name init
```

4. Rodar em modo dev:

```bash
npm run start:dev
```
